  1. **Next server action 的成功路径也是一次 redirect**（必须 redirect 或 throw）。最初用 `.catch(() => {})` 吞掉 —— **那会把真错误一起吞掉，代码坏了也显示测试通过**。改成 `redirectedTo()` 断言跳去了哪一页。
