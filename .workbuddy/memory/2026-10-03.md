### 五层架构（后续改动需遵守）
1. 展示层：Next.js 16.3.4 App Router + React 19.2.8，全部 RSC，因 CSP nonce 必须按请求动态渲染。20 个页面路由，14 个业务组件 + 20 个 shadcn/ui 组件。
2. 查询层：`lib/catalog-query.ts`（URL 是筛选/排序的唯一状态源，`parseCatalogFilters` 服务端与 `catalogFiltersFromURL` 客户端共用解析）+ `lib/catalog.ts`（React `cache` 请求级快照）+ `lib/items.ts`（搜索：NFKC 归一化 + 多词 AND + 字段加权打分 + 短语加成）。
3. 领域层：`data/types.ts` 契约（`Software` / `SeedSoftware` 两种形态）、`lib/input-validation.ts`（URL 白名单、图片魔数校验、媒体路径正则）、`lib/seed.ts`（种子透传映射）、`lib/auth-crypto.ts`（scrypt + HMAC 会话）。
4. 存储层：`lib/store.ts` → `lib/json-store.ts`。4 个 JSON（catalog / feedback / submissions / blocks）+ SHA-256 旁车。按文件绝对路径串行队列、tmp+fsync+rename 原子写、0600 权限、可选 .bak。写路径只经 `updateCatalog`。
5. 外部边界：`proxy.ts`（CSP nonce + /admin 只允许 GET/HEAD/POST）、`lib/guard.ts`（IP 取自 XFF 最右侧、滑动窗口限速、失败封 IP）、`scripts/*.mjs`（backup / content-audit / smoke-detail / seed-drift / hash-password）。

### 关键设计判断（改动前必读）
- **防盗链方向不能反**：站内图片有限可防，爬虫与分享流量不可枚举。无 Referer 必须放行（地址栏直开/微信内置浏览器/爬虫抓 og:image），否则等于把索引和分享一起废掉。
- **拒绝响应必须 `no-store`**：图片路由本是 `immutable` 一年缓存，403 若带上会被缓存住，改配置后仍不放行。
- **CORP 是第二道防线**：Referer 会被浏览器策略裁剪，`same-origin` 在浏览器侧兜底。
- **统计不存 IP**：否则 clicks.jsonl 变成第二份用户数据。
- **语义层只管跨字段一致性**：单字段必填归各入口校验，否则同一问题在两处不同措辞报错（这正是本轮唯一回归的成因）。
