## 本机截图与 A4 排版经验

- 起 dev server 时若本机 MySQL 未监听（`.env.local` 指 3307），临时用 `STORE_DRIVER=json npm run dev -- -p 3100` 覆盖即可（process env 优先于 `.env.local`），不要改 `.env.local`。
- Chromium 直接用 Playwright 内置那份：`%LOCALAPPDATA%\ms-playwright\chromium-1234\chrome-win64\chrome.exe`；Node 22 内置 `fetch` + `WebSocket` 直连 CDP 就够，不必额外装 playwright。
- **`Page.printToPDF` 会挂死**（实测卡住 2 分钟无输出）。出 PDF 改用 CLI 最稳：
  `chrome --headless=new --disable-gpu --hide-scrollbars --no-pdf-header-footer --virtual-time-budget=8000 --print-to-pdf=out.pdf file:///...`
- 截图别用「整页缩小图」直接塞进文档——1440px 视口缩到半栏后正文只有 2.4pt，不可读。正确做法是**按精确矩形裁切带**（`Page.captureScreenshot` + `clip:{x,y,w,h}`，视口给足高度就不用滚动），在 A4 上以整栏宽 166mm 展示，正文约 5pt、标题清晰。
- A4 排版的像素账：`.page` 210×297mm，上下内边距 15/16mm → 可用高度约 1006 CSS px（96dpi 下 1mm≈3.78px）。逐页预览（`scrollTo(i*1122.5)` + 视口截图）能一眼看出溢出；`overflow:hidden` 会把超出的内容**静默裁掉**，必须逐页看。
- 后台长任务别用 `tail -N` 管道读日志：管道会缓冲，脚本被终止时缓冲里的输出全丢。改用 `> log 2>&1` 重定向再读文件。
