- **发现并修掉一个真问题**：`tests/script-syntax.test.mjs`（P10d 新加的 .mjs 语法闸门）在本机**永远失败**。根因不是脚本有 TS 语法（`node --check` 逐个文件都过），而是它用 `execFileSync` 逐文件起子进程，而**本机任何 spawn 都返回 `EBUSY`** —— `cmd /c echo hi` 也一样，沙箱内外 / 系统 node / 托管 node 全部复现。
  - 换判据：用 TypeScript 编译器 `createProgram` + `getSyntacticDiagnostics`（与 `node --check` 同一套解析器，纯进程内，无环境依赖）。实测三类 TS 语法（`as` 断言 / `: Type` / `import { type X }`）全部检出，正常文件零误报。
  - 排除过的方案：`vm.SourceTextModule`（需 `--experimental-vm-modules`，无标志时是 undefined）、`ts.createSourceFile` 的 `parseDiagnostics`（对 JS 里的 `as` **不报错**，不可靠）、`ts.transpileModule`（同样漏报）。
  - **闸门本身要验证**：往脚本注入三种 TS 语法，确认三个诊断都报出来 —— 否则很容易写出永远绿的测试。另补覆盖面断言（钉住必须扫到的文件），防「扫到 0 个文件 = 全绿」。
- **本机环境事实（后续会再遇到）**：spawn 子进程一律 EBUSY，连 `cmd` 都不行。任何依赖 spawn 的测试 / 脚本在此机器上无法运行，不要误判成代码问题。写测试时优先选进程内方案。

## P11 收尾：默认驱动翻成 mysql（e9b19a2，已同步三分支）

- 计划里 P11 主体（规模闸门 + 全表扫描修复）早已标✅，唯一没做的是 `lib/store.ts` 注释里的待办：「把默认值翻成 mysql」。判定从 `STORE_DRIVER === "mysql"` 改成 `!== "json"`（`store.ts` 与 `catalog.ts` 两处）。
- **核心判断：默认值本身就是一种决定。** `=== "mysql"` 意味着「忘了配就静默退回 JSON」，而 JSON 的代价（整目录读进内存 / 整目录重写）正是迁移要消除的东西 —— 静默降级比启动失败难发现得多。
- **与原计划不同：JSON 实现保留而非删除**（用户选定范围）。理由：① 它是唯一的回滚路径；② `tests/admin-actions.test.mjs` 靠显式设 `STORE_DRIVER=json` 做隔离；③ 删掉会让 `tests/catalog-sql.test.mjs`（双路径一致性闸门）失去对照物。计划文档已同步改写，不留「原计划说要删」的误导。
- **两处门面的判定必须一致**：store 走 json 而 catalog 走 SQL = 写入与读取落在两份数据上，是**静默的数据分裂**而非配置错误。注释里点明了这层关系。
- **验证上的一个坑**：`admin-actions.test.mjs` 自己就设了 json，所以「全量测试 230 项绿」**不足以**证明默认路径真的连库。必须补实机验证 —— 删掉 `STORE_DRIVER` 后直接调 SQL 实现读到真实 items 条数。

## 前端交互与流畅度优化（第一轮）

- **筛选面板点不动**：`FilterPanel` 在 `isPending` 时把整个 `fieldset` 设`disabled`，而服务端重算要几百毫秒（2 万条时聚合约 318ms），这段时间用户连点第二个条件都点不动、界面也不给解释。改为**不阻塞交互，只做视觉提示**（连点由 transition 自动合并）。
- **勾选要乐观**：受控 checkbox 的 checked 来自 URL，服务端返回前界面纹丝不动像没点上。加本地暂存立刻打勾。
- **两个实现坑（都是 lint 先拦住的）**：① 渲染期读 ref + 渲染期 setState（`react-hooks/refs`）② effect 里同步 setState（`react-hooks/set-state-in-effect`）。最终解法是**外壳 + `key={URL签名}`**，URL 一变就整个重挂、本地暂存自然丢弃 —— 比手动清理干净，且顺手覆盖浏览器前进/后退。
- **骨架替换「变淡」**：原先 `isPending` 只把列表降到 opacity-60，但旧内容还留在原地等着被抽走。改为形状照着真实卡片/行的骨架，且**仅在已有内容时显示**（首次进入不该闪）。项目里`ui/skeleton.tsx` 早已存在但从未被使用。
