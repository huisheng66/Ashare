## 一、项目一句话说明

**Ashare** 是按使用场景组织的**软件/工具目录站**。只收录三类合法、可核验来源的条目（厂商正式版应用、脚本小工具、开源项目），**不托管安装包、不收录盗版**。技术上是一个无数据库的 Next.js 16 应用：内容存在本机 JSON 里，靠后台单口令登录维护。

## 四、依赖与调用关系（本次新增，上一版完全缺失）

### 关键调用链（`trace_path` 实测）

```
parseMarkdown        ← GuideSection(hop1)、SoftwarePage(hop2)
                     入口仅 4 行，解析在 parseBlocks / parseInline

parseGuideLines      ← app/admin/actions.saveItem(hop1)
                     └─→ isGuideKind(hop1)   ← 教程行格式解析只被后台保存用到

validateSemantics    ← app/admin/actions.saveItem(hop1) + tests/data-model(hop1,true)

decideHotlink        ← app/media/[...path].route.GET
                       app/icons/[slug].route.GET
                       tests/hotlink(hop1,true)
```

### 三条值得注意的发现

**① `lib/semantics.ts` 是规则中心，但生产调用方只有 1 处。**
`validateSemantics` 的调用者只有 `saveItem` 和一个测试。而 README 声称「后台保存与 `ingest` 脚本共用同一份矩阵」——图谱里 `ingest-item.mjs` **未出现在这条链上**。两种可能：脚本通过其他函数（`inferKind` / `resolveKind`）间接调用，或 README 说法与代码有偏差。**要确认需直接读 `ingest-item.mjs`**——`.mjs` 的跨语言解析有损耗，图谱 CALLS 边以 TS 为主，不能仅凭图谱下结论。

**② 防盗链有两个入口，共用同一判定。** `decideHotlink` 同时被 `/media` 和 `/icons` 使用，与 README「`/media` 与 `/icons` 校验 Referer」一致；图谱补出一个 README 未提的细节：**`/icons` 也在做防盗链**。

**③ 测试与生产调用点一一对应。** `decideHotlink` 与 `validateSemantics` 都有测试调用方，说明这两个安全关键模块有真实覆盖，不是空跑。

### 依赖密度

测试文件占据 CALLS 出边榜首（`guide.test.mjs` 16 · `data-model.test.mjs` 16 · `catalog.test.mjs` 14 · `seed.test.mjs` 12 · `stale.test.mjs` 9），符合测试密集型项目特征。

生产代码里最高的是 **`lib/catalog.ts`（仅 2 条出边）**——图谱显示 lib 层内部调用相当少，模块之间靠数据传递而非函数嵌套，与「lib 是无 React 依赖的纯逻辑层」的设计一致。脚本里 `merge-guides.mjs` 最高（7 条），对应它那套行级扫描定位逻辑。

## 十一、关键约束（改代码前必读）

1. **来源与类型必须自洽** —— `lib/semantics.ts` 定义矩阵。标 `opensource` 却无 GitHub 链接，`--strict` 下拦下。**图谱提示：生产调用方仅 `saveItem` 一处，改语义时务必确认 ingest 脚本是否同步。**
2. **只有全部链接都可达才回写 `linksCheckedAt`** —— 否则死链被永久掩盖。
3. **CI 用 `--check-all` 而非只查过期的** —— 门槛决定"何时必须复验"，不限制"能查什么"。
4. **后台正文按纯文本渲染**（不解析 HTML/Markdown）→ 无存储型 XSS。
5. **防盗链是"白名单放行 + 其余拒绝"** —— 图谱证实 `/media` 与 `/icons` **共用** `decideHotlink`。
6. **点击数据不存 IP 与 UA** —— `click-store.ts` 写入路径已核实无此字段。
7. **`proxy.ts` 注入 per-request nonce CSP** —— 公开页面必须按请求渲染，根布局不能静态化。
8. **本地 JSON 存储只适用单进程 + 持久磁盘**。
9. **`lib/seed.ts` 加透传字段时必须同步 `scripts/seed-drift.mjs`** —— 漏了会让漂移检测对该字段**静默失明**（该脚本 22-25 行注释记录了这个真实踩过的坑）。
